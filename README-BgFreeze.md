# BgFreeze (Background Freeze)

Модуль для Magisk / KernelSU, который замораживает фоновые процессы и включает агрессивный Doze для экономии батареи и снижения нагрева на Xiaomi.

## Что делает

- Отключает фоновую активность для всех пользовательских приложений
- Блокирует фоновые службы Google (GMS Doze)
- Отключает аналитику Xiaomi (MIUI Analytics, Daemon, Hybrid)
- Отключает энергозатратные службы Joyose и MiBrain
- Включает агрессивный Doze (глубокий сон)

## Установка

1. Скачай ZIP из Releases
2. Magisk / KernelSU → Модули → Установить из хранилища
3. Перезагрузи телефон

## Совместимость

- Устройства: Xiaomi (тестировано на Mi 11 Ultra)
- Прошивки: MIUI / HyperOS / Xiaomi.eu
- Android: 12-14
- Root: Magisk или KernelSU
